# MyMzansi Skills - Project Overview (v2)

## Overview

MyMzansi Skills is South Africa's digital career passport. It allows job seekers — especially recent TVET and university graduates as well as working professionals — to securely store, verify, and showcase their certifications, skills, and professional achievements in one trusted place.

The platform helps reduce qualification fraud and makes it easier for employers and recruiters to discover credible talent.

## Goals

1. Deliver a beautiful, trustworthy, and easy-to-use experience that users are proud to share.
2. Significantly increase profile completion rates and credential density.
3. Begin providing real value to employers through better discoverability of public profiles.
4. Build a solid, maintainable foundation for future institution verification and deeper integrations.

## Core User Flow (v2)

1. User signs up from landing page.
2. Guided onboarding helps them quickly complete their profile.
3. Adds credentials, experience, and skills.
4. Toggles profile public and shares their professional link + CV.
5. Monitors basic profile views.

## Features

### Completed in v1
- Supabase Auth + Dashboard
- Profile Management
- Credential Management (with file upload)
- Public Profile Page (`/profile/[slug]`)
- Profile visibility + shareable link
- Basic CV PDF generation
- Static employer informational page

### New in v2
- **Visual & UX Polish** — Professional, premium feel across all pages
- Experience & Skills Management
- Improved Onboarding + Profile Completeness Score
- Basic Public Directory / Talent Browse (for employers)
- Enhanced Credential Cards and Document Experience
- Better CV Templates
- Basic Profile View Analytics

## In Scope (v2)

- Major visual and UX improvements
- Experience and Skills sections
- Simple public directory with basic search
- Profile completeness guidance
- Enhanced CV generation
- Mobile-first polish and consistency

## Out of Scope (v2)

- AI competency analysis or matching
- Full institution verification system
- Government integrations (Home Affairs, SAQA, etc.)
- Advanced employer tools (messaging, applications, saved candidates)
- Payments or subscriptions
- Social features / endorsements
- Custom domains or advanced analytics

## Success Criteria (v2)

1. The app looks and feels professional — users are proud to share their public profile.
2. New users complete significantly more of their profile (target: 60%+ completion rate).
3. Employers can easily browse and discover public profiles.
4. The end-to-end experience (from sign-up to sharing) feels smooth and delightful.
5. Codebase remains clean, maintainable, and follows all established architecture standards.
